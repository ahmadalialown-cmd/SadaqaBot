# صدقة جارية — دليل النظام

نظام ينشر بشكل تلقائي على حساب انستقرام **@9d8h0garyh** (الاسم الظاهر «صَدقة»، صدقة جارية عن سعود القحطاني رحمه الله).
وما ينشر على أي حساب غيره: إذا التوكن طلع لحساب ثاني، يوقف النشر بنفسه.
الربط مع Meta يمر عبر صفحة فيسبوك اسمها «صدقة جارية». هذي الصفحة جسر بس، ومحد يشوفها.

**المحتوى اليومي:**
- **ستوريز الأذكار** تنشر شرائح منشوراتك نفسها، بالترتيب: «أذكار الصباح» بعد الفجر، و«أذكار المساء» بعد العصر، و«أذكار النوم» الساعة ١٠ الليل.
  ما في طريقة عبر الـ API لزر «مشاركة المنشور في الستوري»، فتنزل كصور ستوري عادية.
  إذا عدّلت على منشورات الأذكار، شغّل `.venv\Scripts\python bot\adhkar_stories.py` عشان يسحب الشرائح الجديدة.
- **بوست المغرب** فيه أثر من كتاب «الزهد» للإمام أحمد، منقول بنصه من طبعة دار الكتب العلمية ١٤٢٠هـ (نص المكتبة الشاملة).
  القائمة في `data/athar.yaml`، وما في أثر يتكرر.
- **الجمعة:** بوست العصر عن الصلاة على النبي ﷺ، وبوست المغرب دعاء لسعود.

الجدول القديم (للمرجع):
- **ستوري أذكار الصباح**: بعد الفجر بـ ٢٠ دقيقة
- **ستوري أذكار المساء**: بعد العصر بـ ٢٠ دقيقة
- **ستوري أذكار النوم**: الساعة ١٠ الليل
- **بوست يومي وقت المغرب**: آية، أو حديث صحيح
- **كل جمعة**: بوست وقت العصر عن الصلاة على النبي ﷺ، وبوست المغرب دعاء لسعود

أوقات الصلاة تنحسب لحالها على طريقة وزارة الأوقاف القطرية (الدوحة).
**ما ينشر إلا شي إنت معتمده.**

> ⚠️ المحتوى الديني: الآيات من نص المصحف (Tanzil)، والأذكار من حصن المسلم، والأحاديث من الصحيحين بس.
> ومع هذا، خل طالب علم يراجعها قبل ما تعتمدها.

كل الأوامر تنكتب في PowerShell داخل فولدر `C:\SadaqaBot`.

## ١) اعتماد أسبوع

```bash
.venv\Scripts\python bot\review.py --days 7
```
يفتح لك صفحة `review\review.html` فيها كل صورة مع نصها ووقتها ومصدرها. إذا عجبتك:
```bash
.venv\Scripts\python bot\approve.py --days 7
git add -A
git commit -m "approve week"
git push
```
- تبي تشيل عنصر؟ `.venv\Scripts\python bot\approve.py --reject 2026-11-10-maghrib`
- تبي تشوف كم عنصر معتمد؟ `.venv\Scripts\python bot\approve.py --status`

أو بكل بساطة قول لـ Claude: «اعتمد الأسبوع الجاي».

## ٢) إضافة محتوى
- **آيات**: ضيف سطر في `data/verses.yaml` بهالشكل `[رقم السورة, أول آية, آخر آية, "العنوان"]`. نص الآية ينسحب من المصحف بنفسه.
- **أحاديث**: في `data/hadith.yaml`، وما يدخل إلا حديث صحيح ومعه مصدره ورقمه.
- بعدها شغّل:
```bash
.venv\Scripts\python bot\build_bank.py --days 90
```
الجديد يدخل بحالة «pending» (ينتظر اعتمادك)، واللي معتمد من قبل ما يتغيّر.

## ٣) إضافة ريلز
1. حط الفيديو في فولدر `reels_inbox\` وسمّه برقم السورة والآية، مثل `51-17.mp4` أو `2-285-286.mp4`.
2. شغّل:
```bash
.venv\Scripts\python bot\reels.py --time "2026-11-20 20:00"
```
يحط خلفية بلون الحساب، ويكتب الآية فوق الفيديو، ويضيفه للقائمة بانتظار اعتمادك.

## ٤) إيقاف كل شي (مفتاح واحد)
في ملف `config.yaml` غيّر السطر إلى:
```
paused: true
```
وبعدها `git commit` و `git push`، ويوقف النشر كله. ترجّعه `false` عشان يرجع يشتغل.

`auto_approve: false` معناه ما ينشر إلا اللي إنت معتمده. خله `false`.

## ٥) إذا انتهى التوكن
GitHub بيرسل لك إيميل إن الـ workflow فشل، وبيطلع في السجل «التوكن منتهي».
وصلاحية الوصول للبيانات عند Meta تحتاج تجديد كل ٩٠ يوم تقريباً، والنظام ينبهك قبلها بأسبوعين.
1. افتح https://developers.facebook.com/tools/explorer/ واختار تطبيق **SadaqaBot**.
2. تأكد إن الصلاحيات الخمس موجودة، واضغط **Generate Access Token**، واختار صفحة «صدقة جارية» وحساب @9d8h0garyh.
3. شغّل:
```bash
powershell -ExecutionPolicy Bypass -File C:\SadaqaBot\setup_secrets.ps1
```
انسخ التوكن واضغط Enter، وبعدها انسخ App Secret (من إعدادات التطبيق ← أساسي) واضغط Enter. الترتيب ما يفرق.
