## 🔴 مفتاح الإيقاف (واحد بس)
في ملف `config.yaml` على GitHub غيّر السطر إلى:
```

```
احفظ التعديل (Commit)، ويوقف كل شي: النشر، والتواصل مع Meta، والتقرير.
ترجّعه `false` عشان يرجع يشتغل.
تقدر تعدّله من الجوال: افتح الريبو ← `config.yaml` ← رمز القلم ✏️.

## 🐢 البداية التدريجية (بعد قفل الحساب في ٧ نوفمبر)
تبدأ لحالها يوم **١٠ نوفمبر ٢٠٢٦**، وقبل هالتاريخ النظام ما يكلم Meta أبداً:
- **الأسبوع الأول:** بوست واحد باليوم (المغرب).
- **الأسبوع الثاني:** اثنين باليوم (البوست والريلز).
- **من ٢٤ نوفمبر:** الجدول كامل، ويضل بين كل نشر والثاني فاصل، وما يتعدى ٦٠ نشر باليوم (حد Meta ١٠٠).

## 🛟 الإصلاح الذاتي
- **إذا حدّت Meta من النشر (rate limit):** يوقف ٢٤ ساعة ويرجع لحاله.
- **إذا Meta منعت أو علّقت إجراء:** يوقف ٧٢ ساعة، وبعدها يجرب مرة وحدة.
- **إذا التوكن انلغى أو الحساب انقفل:** يوقف، ويفحص مرة وحدة كل ٢٤ ساعة، ويرجع لحاله أول ما يصلح.
- **إذا فشل ٣ مرات ورا بعض لسبب ثاني:** يوقف ٦ ساعات.
- **في كل إيقاف أو رجعة** يفتح Issue في GitHub، وGitHub يرسل لك إيميل. وما يكرر المحاولة ورا بعض أبداً.

## 📊 التقرير الأسبوعي (إيميل)
كل جمعة الساعة ١:٣٠ الظهر:
- يزيد المحتوى لحاله بحيث يضل فيه ٣٠ يوم قدام على الأقل.
- يرسل لك التقرير على الإيميل (Issue)، وفيه: الوصول والإرسال والحفظ لكل نوع محتوى، وأفضل وقت للريلز، والتعليقات الجديدة، وتنبيه يوم توصل ٢٠٠ متابع عشان تفعّل Trial Reels.
- يغيّر وقت الريلز لحاله إذا لقى وقت أفضل.

## ✅ الاعتماد
`auto_approve: true`: المحتوى ينتشر بدون ما يحتاج مراجعة كل أسبوع (شغّلناه بطلبك بعد ما اعتمدت أول أسبوع).
كل المحتوى منقول من مصادر موثوقة، وفيه اختبارات تتأكد إن النص مطابق للمصدر:
- القرآن من Tanzil.
- الأذكار من حصن المسلم.
- الآثار من الزهد، طبعة دار الكتب العلمية.
- التفسير من السعدي.

إذا تبي ترجع للمراجعة الأسبوعية، خلها `auto_approve: false`، وبعدها:
```bash
.venv\Scripts\python bot\review.py --days 7
.venv\Scripts\python bot\approve.py --days 7
```

## 🔑 إذا انتهى التوكن (يوصلك إيميل)
صلاحية Meta تحتاج تجديد يدوي كل ~٩٠ يوم، وهذا شي ما يقدر النظام يسويه بروحه. وبيرسل لك إيميل قبلها بأسبوعين.
1. افتح https://developers.facebook.com/tools/explorer/ ← SadaqaBot ← **Generate Access Token** ← اختار صفحة «صدقة جارية» و@9d8h0garyh.
2. شغّل:
```bash
powershell -ExecutionPolicy Bypass -File C:\SadaqaBot\setup_secrets.ps1
```
3. انسخ التوكن واضغط Enter، وبعدها انسخ App Secret واضغط Enter. والنظام يرجع لحاله في غضون يوم.
